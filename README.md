# moram

Figma Dev Mode → React 변환 프로젝트. Vite + React + Tailwind + react-router.

## 시작하기
```bash
npm install
npm run dev
```

## 진행 현황
`PROGRESS.md` 참고 — 총 52개 프레임(중복 포함) 중 진행 상황을 체크리스트로 관리합니다.

## 구조
```
src/
  pages/        각 화면 (라우트 단위)
  components/   여러 화면에서 재사용하는 조각 (로고, 배경 장식, 스텝 인디케이터 등)
  assets/       화면별로 폴더를 나눠 보관한 다운로드 에셋(svg/png)
```

## 참고사항
- 인터랙티브 화면(로그인, 회원가입 등)은 실제로 입력·검증·페이지 이동이 동작하도록 `useState` +
  `react-router-dom`으로 구현했습니다. API 연동이 필요한 지점은 `// TODO` 주석으로 표시해뒀습니다.
- 원본 Figma 디자인에 다음 동작 버튼이 없는 화면(정보입력 폼, 가입완료)에는 실제 사용을 위해 버튼을
  추가했고, 코드에 그 사실을 주석으로 남겨뒀습니다.
- 첫 화면(랜딩 히어로)만 예외적으로 절대좌표 % 스케일링 방식을 씁니다 — 일러스트가 배경 전체를
  채우는 특수 케이스라서 그렇습니다. 나머지 화면은 전부 일반적인 flex/grid 반응형 레이아웃입니다.
