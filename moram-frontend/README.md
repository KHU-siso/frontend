# 모람 프론트엔드 목업

React + Vite + JavaScript로 만든 1차 프론트엔드 뼈대입니다.

## 실행

```bash
npm install
npm run dev
```

## 구현된 화면

- 이메일 로그인 / 로그아웃
- 로그인 보호 라우팅
- 대시보드
- 과제 목록
- 과제 상세 / 목업 제출
- 커뮤니티 목록
- 게시글 상세 / 댓글 등록
- 게시글 작성
- 나머지 메뉴 라우팅용 플레이스홀더
- PC / 모바일 반응형 레이아웃

## 다음 단계

- 디자이너 시안에 맞춰 CSS 교체
- 백엔드 API 명세에 맞춰 `src/data/mockData.js`를 API 호출 계층으로 교체
- 인증, 과목, 캘린더, 퀴즈, AI 채팅 기능 추가

## 목업 로그인

이메일 형식의 아이디와 아무 비밀번호를 입력하면 로그인됩니다. 로그인 상태는 브라우저 localStorage에 저장됩니다.
